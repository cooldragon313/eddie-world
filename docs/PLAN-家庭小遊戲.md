> 2026-10-29 Bernie 口述，大黑整理。**還沒動工**，等 Bernie 點頭挑第一款。
> 概念：用幾個家庭的真實日常做成一系列「一二三木頭人」小遊戲。
> 大人一轉頭你就作亂，大人一看你就要裝乖。

## 一、共用骨架（做一次，每款共用）

全部小遊戲都是同一個「木頭人引擎」換皮，所以第一款做完，後面每款都便宜。

| 零件 | 做什麼 |
|---|---|
| **看守者**（媽媽 / 嬤嬤） | 狀態循環：沒在看 → **轉頭預兆** → 在看 → 沒在看。每段時間隨機 |
| **預兆** | 腳步聲、門把聲、台詞、影子。預兆到真的轉頭大約 1 秒，給你反應時間 |
| **假動作** | 越玩越常出現：腳步聲靠近又走掉、只瞄一眼。這是緊張感的來源 |
| **兩種狀態** | 作亂（得分）/ 裝乖（安全但扣心情或不得分） |
| **貪心曲線** | 越好玩的作亂，收起來越慢 → 貪心就容易被抓 |
| **被抓** | 卡通處罰（「啪」字、星星、畫面一震，不流血、不哭哭），看守者**怒氣值**上升 |
| **結束** | 怒氣值爆表 → Game Over。撐越久越難（轉頭越快、假動作越多） |
| **獎勵** | 分數換金幣，存進海嘯島帳號；每款各一張排行榜（沿用現有系統） |
| **入口** | 首頁選關畫面多一排「家庭小遊戲」，每款一頁 |

## 二、第一款：拆家寶寶（媽媽整天念小孩破壞環境）

- **場景**：客廳。一兩歲寶寶在遊戲墊上吸奶嘴；媽媽在沙發看電視。
- **媽媽的行程**（隨機穿插）：
  - 燒開水：短，水壺叫就回來
  - 講電話：中等，邊講邊走，偶爾回頭瞄
  - 煮飯：長，最好拆
- **能拆的東西**：
  - 衛生紙抽光
  - 盆栽推倒
  - 蠟筆畫牆
  - 餅乾倒地毯
  - 遙控器丟魚缸
  - 越大分數越高、要按越久
- **裝乖** = 坐下吸奶嘴：
  - 在墊子上最安全
  - 在墊子外被看到，怒氣小漲
  - 拆到一半被抓，怒氣大漲
- **被抓**：被拎回墊子 + 屁屁輕拍一下。
- **比的是**：破壞分數。

## 三、第二款：熱熔膠條之夜（兒子讀書不認真）

風格：**恐怖熊式的第一人稱夜間緊張感**（自己原創，不照抄任何遊戲）。

- **場景**：第一人稱看書桌。背後是房門；桌上有小鏡子／螢幕反光可以看到門口。時鐘從晚上 8:00 走到 10:00。
- **裝乖**：
  - 看課本，心情慢慢**往下掉**
  - 很久沒翻頁，嬤嬤會起疑：「你那頁看多久了？」→ 要記得偶爾翻頁
- **偷玩**（心情往上加，越爽越難藏）：

  | 偷玩 | 心情 | 收起來要多久 |
  |---|---|---|
  | 課本空白處畫畫 | 低 | 超快 |
  | 漫畫夾在課本裡 | 中 | 快 |
  | 手機偷看 YouTube | 高 | 中 |
  | 平板打電動 | 最高 | 慢 |

- **預兆**：
  - 走廊腳步聲（有左右聲道）
  - 門縫下的影子
  - 門把轉動聲
  - 台詞：「功課寫完了沒？」
  - 假動作：腳步到門口又走掉
- **被抓**：
  - 熱熔膠條「咻——啪！」，畫面一震，心情大扣，怒氣大漲
  - 連續被抓，嬤嬤會守在門口一段時間（壓力拉滿）
- **結束**：
  - 嬤嬤爆炸 → Game Over
  - 撐到 10:00 → 過關加碼
- **獎勵**：**心情 = 金幣**。

## 四、怎麼做比較「有感」（重點）

1. **聲音加分，但靜音一定玩得了**（Bernie 2026-10-29：小孩都是靜音偷玩）。每個聲音預兆都要有畫面版：
   - 腳步聲 → 畫面邊緣的腳印圖示，越近越大越紅
   - 門把聲 → 鏡子裡門把轉、門縫透光
   - 台詞 → 字幕泡泡
   - 假動作 → 腳印變淡退走
   - 咻啪 → 「啪」字＋畫面震；Android 加手機震動（iPhone 網頁不支援）
   - 開聲音的人額外多一層恐怖感
2. **家族真實台詞**：媽媽 / 嬤嬤的口頭禪用家裡真的講法 → 自己家人玩到會大笑，這是別的遊戲抄不走的。**需要 Bernie 提供台詞清單。**
3. **假動作比轉頭更可怕**：腳步聲靠近又走掉，那一秒心臟會停。
4. **貪心有代價**：最爽的偷玩最難藏，讓人自己決定要不要賭。
5. **短局**：2～3 分鐘一局，輸了馬上重來（沿用 🔄 重來）。
6. **結算卡可分享**：「今晚偷看 YouTube 12 分鐘、被抽 3 下、嬤嬤怒氣 98%」→ 截圖丟 LINE 群、同學之間比。
7. **越來越難**：時間越晚，嬤嬤轉頭越快、假動作越多，排行榜才分得出高手。
