## 我的家（預設做法，Bernie 沒反對就照這個）
- **室內房間、動森式擺家具**：一進來就在自己的房間
- 房間是格子地板（例如 8×8），家具佔 1×1 或 2×1 格
- 操作：點家具 → 拖到格子上 → 點「轉」→ 放好；再點一下可以收回
- 手機：單指拖家具、雙指轉鏡頭／縮放
- 角色可以在家裡走動，造型（帽子、背包…）照舊
- 家具店：沙發、床、桌椅、電視、書櫃、地毯、盆栽、燈、海報、土星玩偶…，加上換**地板**、**壁紙**
- 存檔：伺服器每個帳號存一份 `home`（家具 id、格子位置、方向、地板、壁紙）

## 家裡的入口
- 牆上一扇**門**＝「出門玩」→ 選關卡畫面（逃離土星／恐怖考前複習夜／屁孩拆客廳）
- 關卡結束 → 「回家」按鈕，帶著金幣回來
