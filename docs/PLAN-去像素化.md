## ✅ 定案風格規格：Q 版 · 繪本
> 參考實作：`demo-styles.html` 的 `QV.book`（試玩 https://claude.ai/artifact/JzZMRGcv6rfDiLhQG9Rjmg#chibi-book ）

| 項目 | 規格 |
|---|---|

| 材質 | `MeshToonMaterial`，明暗 **4 階**（115 / 165 / 210 / 240） |
| 描邊 | **咖啡色 `#5b3a29`**，背面放大法，粗細為原版的 **0.6 倍** |
| 顏色 | 所有物件顏色 飽和度 −0.10、亮度 −0.03（不刺眼） |
| 光線 | 半球光 0.78（暖白 `#fff2dc`／地面 `#b9d99c`）＋太陽 0.55（`#ffeccc`） |

> 目標一句話：**保留所有玩法，只把「方塊、像素、電腦字」的感覺換成「圓潤、可愛、有質感」**

## 1. 現況盤點（我看完程式碼的結論）

| 項目 | 現在怎麼做 | 為什麼看起來「像素」 |
|---|---|---|
| 技術 | Three.js r128，全部寫在 `index.html`（5,132 行） | — |
| 角色 | `buildAvatar()` 用 **20 幾個方塊** 拼成（頭、身、手、腳、眼睛都是方塊） | Minecraft 感的主要來源 |
| 海嘯 | `createTsunami()` = **一面方形牆 + 一排白方塊當浪花** | 像一堵彩色積木牆，不像水 |
| 金幣 / 寶箱 / 道具 | `makeCoinMesh()` / `makeChestMesh()` / `makePowerupMesh()`，多數是方塊 | 一樣是積木 |
| 材質 | 38 處 `MeshLambertMaterial`（純色、沒有光澤） | 塑膠、扁平 |
| 字體 / UI | **全部 `font-family: monospace`**，字距拉開 | 「電腦終端機 / 像素遊戲」感很重 |
| 畫質檔 | G 鍵切 Off / Basic / Polished / Cinema（已有 bloom、FXAA、陰影） | 底子不錯，可以沿用 |
| 伺服器 | `party/server.js` 只管位置、金幣、帳號 | ✅ **畫面改動完全不用碰伺服器** |

👉 **好消息**：玩法跟連線都在伺服器和邏輯層，畫面是獨立的「外皮」，可以一塊一塊換，不會把遊戲弄壞。

## 2. 三條路（推薦 A）

### 🅰 圓潤化：方塊 → 圓角／球／膠囊 ⭐ 推薦
- 角色改成圓頭、圓身、膠囊手腳（類似 Fall Guys、Roblox 新版）
- 材質換成有光澤的 `MeshStandardMaterial` 或卡通風 `MeshToonMaterial`
- 海嘯改成會起伏的「真水面」＋泡沫粒子
- **優點**：不用找外部模型，捏臉／造型系統可以保留；風險最低；可以分批上線
- **缺點**：上限是「精緻的可愛風」，不會變寫實

### 🅱 換真的 3D 模型（GLTF 檔）
- 用免費的 CC0 模型包（如 Kenney、Quaternius）替換角色和道具
- **優點**：畫面跳一大級，角色有骨架動畫
- **缺點**：捏臉、20 件造型要全部重做；模型檔變大，平板可能變卡；工作量約 A 的 3 倍

### 🅲 改成 2D 插畫風
- 等於重寫遊戲 → ❌ 不建議

## 4. 要注意的事

1. **正式版會直接影響小孩**：GitHub Pages 是 `main` 分支一推就上線 → 改動先放分支，確認 OK 再合併
2. **平板效能**：小孩用什麼裝置玩？圓形物件面數比方塊多，要控制
3. **多人一致**：別人看到的角色也要一起換（`buildAvatar` 是共用的，這點 OK）
4. **舊存檔**：外觀改動不碰存檔資料，造型 ID 保持不變即可

## 5.5 💡 點子池：「自拍 → 遊戲風格大頭」（2026-10-15 提出，未決定）

**想法**：進入世界前拍照或上傳照片 → 轉成遊戲風格 → 變成角色的臉。

| 做法 | 怎麼做 | 費用 | 隱私 | 像不像本人 |
|---|---|---|---|---|
| **A. 照片自動捏臉** ⭐ | 手機上用臉部辨識（MediaPipe）分析膚色、髮色、眼鏡、笑不笑 → 自動套用現有捏臉選項 | 免費 | ✅ 照片不離開手機 | 有點像（顏色、特徵） |
| **B. AI 生成大頭貼** | 照片送到伺服器 → 呼叫生圖 API（OpenAI / Gemini）→ 卡通頭像貼在角色臉上 | 每張約 NT$1～6，要 API 金鑰 | ⚠️ 照片會上傳 | 很像 |
| **C. A + B 混合** | 3D 角色用 A；B 只做「個人名片／排行榜頭像」，限家人帳號 | 少量 | 中 | — |

**⚠️ 最大考量：這是公開多人遊戲（最多 100 個陌生人）**
- 12 歲小孩的臉會被陌生人看到 → 建議：真臉頭像**只有自己看得到**，或只開放給家人帳號
- ChatGPT 的免費額度**不能**給遊戲用（那是聊天 App 的額度，不是程式用的 API）

### ✅ 決定採用：D. 玩家自己生成、上傳（2026-10-15）
> 使用者想法：遊戲提供一段**統一提示詞**，想用的人自己拿去 ChatGPT 生，生完上傳。開不開、給不給別人看，由玩家自己決定。先自己玩，真的做大再說。

**流程**：
1. 創角／造型店多一顆「📷 自訂大頭」按鈕
2. 點開 → 顯示**統一提示詞**＋「複製」按鈕＋簡單教學（打開 ChatGPT → 貼上提示詞 → 附上自拍 → 下載圖）
3. 玩家上傳生好的圖 → 遊戲自動**裁正方形、縮成 128×128**（約 10～20KB）
4. 貼到角色頭的正面
5. 開關：☐ 使用自訂大頭　☐ 讓其他玩家看到（預設**不給看**）

**為什麼好**：遊戲不用付 AI 費用、不用 API 金鑰、不碰原始照片（只收到卡通圖）

**要做的事**：
- 前端：上傳、裁切、縮圖、貼臉
- 伺服器：存一張小圖（跟帳號綁）、轉發給其他玩家（如果有開分享）
- 管理後台：加「刪除某人大頭」按鈕（萬一有人上傳奇怪的圖）
- 提示詞：**等風格選定後定稿**（要畫成跟遊戲一樣的風格），草稿如下

**提示詞草稿**（之後依選定風格替換 `[STYLE]`）：
```
Turn the person in my photo into a game avatar head in [STYLE] style.
Front view, looking straight at the camera, head and a bit of neck only,
centered, square 1:1 image, transparent background.
Keep their hair style, hair color, skin tone, glasses and face shape so
friends can recognize them, but make it a cute cartoon game character,
not a realistic photo. Simple clean shapes, bright colors, no text.
```

**排程**：等風格選定、P5 角色改版時一起做（臉要配合新角色頭型）
